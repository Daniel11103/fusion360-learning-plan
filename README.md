# Fusion 360 零基础学习计划

这是一套面向零基础学习者的 Fusion 360 学习路线，按 **12 周、每周 5 天、每天 60-90 分钟** 设计。

目标是能够独立完成常见零件建模、参数化设计、基础装配、工程图、3D 打印准备和简单 CAM 准备。

## 使用方法

1. 安装 Fusion 360，并确认使用个人学习/非商业许可或教育许可。
2. 在 Fusion 360 中创建一个项目，例如 `Fusion360-Learning`。
3. 每次练习保存三个版本：`练习名_v01`、`练习名_v02`、`练习名_final`。
4. 每次学习记录四项内容：今天使用的命令、遇到的问题、一个技巧、成品截图。
5. 每个模型至少完成两次：第一次跟着教程，第二次不看教程独立重做。

## 每日课程目录

每周一个文件夹，每天一个 Markdown 课件。打开当天文件，按“今日目标 → 课程内容 → 动手练习 → 视频学习链接 → 本节重点总结 → 完成检查”的顺序学习。完成课件示例不等于掌握，必须另外完成独立重做和变式测试。

## 学习掌握度评估

请先阅读 [ASSESSMENT.md](ASSESSMENT.md)。每天按 100 分评分：概念解释 15 分、跟练结果 15 分、独立重做 30 分、变式测试 25 分、错误排查 10 分、文件规范 5 分；**80 分以上才算当天达标**。至少保存 `guided`、`independent` 和 `variant` 三个版本。

判断是否真正掌握的关键问题是：**关闭课件后，能否从空白文件完成一个新条件，并解释为什么这样建模？** 如果只能照着视频画出相同外形，不能通过参数变化、换尺寸或换结构的测试，就先不要算掌握。

## 核心英文词汇

`Sketch`、`Extrude`、`Revolve`、`Fillet`、`Chamfer`、`Shell`、`Pattern`、`Mirror`、`Component`、`Joint`、`Drawing`、`Manufacture`。

## 12 周学习路线

### 第 1 周：界面与约束草图

**目标：** 能画出完全约束的二维草图，并理解参数化建模。

- 认识 Browser、Timeline、Canvas、Data Panel。
- 练习视图旋转、平移、缩放、正视图和等轴测视图。
- 学习 Line、Rectangle、Circle、Arc、Polygon、Slot。
- 学习 Coincident、Horizontal/Vertical、Parallel、Perpendicular、Tangent、Concentric、Equal、Symmetry。
- 学习尺寸标注和约束冲突处理。

**练习项目：** 带两个圆孔的安装板、对称支架、桌面理线夹或手机支架底板。

**验收标准：** 至少完成 1 个包含 2 次拉伸和 2 个圆孔的零件；重要草图显示 `Fully Constrained`。

### 第 2 周：常用实体建模

**目标：** 掌握最常用的零件建模命令。

- `Extrude`：拉伸、切除、对称拉伸。
- `Revolve`：创建轴类和回转类零件。
- `Hole`：标准孔、沉孔、沉头孔和螺纹孔。
- `Fillet` 与 `Chamfer`：圆角和倒角。
- `Shell`：创建有壁厚的容器。

**练习项目：** 六角旋钮、轴套、小收纳盒、瓶盖。

**验收标准：** 能判断零件适合使用拉伸还是旋转；能独立制作一个有壁厚的盒子。

### 第 3 周：构造几何与复杂特征

**目标：** 掌握非默认平面、镜像和阵列。

- Construction Plane、Construction Axis。
- Project / Include。
- `Mirror`、`Rectangular Pattern`、`Circular Pattern`。
- `Combine` 的合并、切除和求交。

**练习项目：** 四孔法兰盘、U 型支架、通风外壳、简易齿轮外观模型。

**验收标准：** 能在偏移或倾斜平面上建模；能使用阵列和镜像完成重复结构。

### 第 4 周：参数、表达式与设计意图

**目标：** 让模型通过参数变化，而不是只能适配一个固定尺寸。

建议建立以下用户参数：

```text
length = 120 mm
width = 80 mm
height = 35 mm
thickness = 3 mm
hole_diameter = 5 mm
margin = 10 mm
hole_spacing = length - 2 * margin
```

**练习项目：可调尺寸电子设备外壳**

要求：

- 外壳长宽高由参数控制。
- 壁厚由参数控制。
- 螺丝孔随外壳尺寸变化并保持边距。
- 增加 USB 开口和通风孔。
- 将长度从 120 mm 改为 160 mm 后，模型仍能正常更新。

### 第 5 周：从实物到模型

**目标：** 学会测量、拆分特征并按合理顺序建模。

选择一个简单实物，例如门把手底座、遥控器背盖、夹子、塑料盒或金属角码。

执行流程：

1. 测量总体长宽高。
2. 将对象拆成主体、凸台、孔、槽、圆角和倒角。
3. 先做主体，再做切除和重复结构，最后处理圆角。
4. 每一步都检查尺寸、约束和视图。
5. 将模型与实物对比并记录误差。

**验收标准：** 完成一个实物复刻模型；时间线至少有 8 个合理命名的特征；能解释特征顺序。

### 第 6 周：Body 与 Component

**目标：** 分清实体和组件，为装配做好准备。

- `Body` 是单个实体几何。
- `Component` 是独立零件或子装配，有自己的原点、草图和实体。
- 需要独立移动、复制、装配或出 BOM 的对象，应建立为 Component。
- 避免把一台产品的所有零件都堆在一个 Component 里。

**练习项目：** 分别建立螺栓、螺母和垫片三个 Component；再制作由底座、盖板、旋钮组成的小盒子。

### 第 7 周：装配与运动

**目标：** 建立真实的零件连接关系并让零件运动。

- `Joint` 和 `As-Built Joint`。
- Rigid、Revolute、Slider、Cylindrical、Planar。
- Joint Origin、Motion Link 和 Ground。

**练习项目：** 铰链盒、丝杆滑块简化模型、简易夹具。

**验收标准：** 盒盖能绕正确轴线旋转；滑块能沿导轨移动；装配中至少固定一个基准零件。

### 第 8 周：工程图

**目标：** 将三维模型表达为可制造和可检验的二维图纸。

- `Drawing > From Design`。
- 三视图、等轴测图、剖视图、局部视图。
- 尺寸标注、中心线、中心标记、标题栏、比例和单位。
- 导出 PDF 或 DWG。

**练习项目：** 为第 5 周的实物复刻模型创建一页工程图，标出总长、总宽、总高、孔径、孔距和关键台阶尺寸。

**验收标准：** 关键尺寸不依赖看图估计；同一尺寸不重复标注。

### 第 9 周：材料、外观与渲染

**目标：** 用效果图清楚表达材料和设计意图。

- Physical Material 与 Appearance 的区别。
- Render 工作区中的场景、光源、相机和分辨率。
- Decal 的基本使用。

**练习项目：** 给电子外壳设置 ABS 塑料外观，给螺丝设置金属外观，输出正视、45 度视角和爆炸视角图。

### 第 10 周：3D 打印或 CAM 入门

#### 3D 打印方向

- 检查壁厚、悬垂、间隙和倒角。
- 导出 STL 或 3MF 前确认单位。
- 配合间隙可先从 `0.2-0.4 mm` 范围测试。
- 设计孔径、卡扣、间隙和桥接测试件。

**练习项目：** 可打印抽屉标签夹、耳机支架或电线固定夹。

#### CNC / 加工方向

- 了解 Manufacture 工作区。
- 设置毛坯、原点和坐标方向。
- 学习 2D Contour、2D Pocket 和 Drilling。
- 了解刀具、转速、进给和仿真。
- 在真实机床加工前，必须进行仿真并请有经验的人复核。

### 第 11 周：完整项目规划

从下面选择一个真实会使用的项目：

- 树莓派或开发板外壳
- 可调手机支架
- 桌面耳机支架
- 小型抽屉分隔系统
- 带铰链的收纳盒
- 简易夹具
- 键盘或鼠标收纳底座
- 摄像头安装支架

项目规划清单：

1. 写出使用场景和约束。
2. 列出必须尺寸。
3. 列出零件清单。
4. 判断哪些零件需要独立 Component。
5. 定义关键参数。
6. 先手绘结构，再进入 Fusion 360。
7. 建模时保持时间线清晰命名。
8. 建立装配关系。
9. 输出工程图或 3D 打印文件。
10. 输出一张最终展示图。

### 第 12 周：完成、复盘与迭代

1. 检查是否存在未完全约束的重要草图。
2. 检查是否有报错特征和不必要的重复几何。
3. 统一零件、组件和特征名称。
4. 修改一次设计需求，例如外壳加长 20 mm 或移动孔位。
5. 验证模型能否稳定更新。
6. 整理 Fusion 设计文件、PDF 工程图、STL/3MF 或 CAM 设置、渲染图和一页项目说明。

## 推荐练习顺序

1. 带孔矩形板
2. L 型角码
3. 旋钮
4. 轴套
5. 小收纳盒
6. U 型支架
7. 四孔法兰
8. 手机支架
9. 带盖电子外壳
10. 铰链收纳盒
11. 可调夹具
12. 一个完整可制造项目

## 每次建模的固定流程

1. 确认单位，机械设计通常使用 mm。
2. 确定原点和基准面。
3. 建立完全约束草图。
4. 用拉伸或旋转完成主体。
5. 增加孔、槽、壳体、阵列和镜像。
6. 最后处理圆角、倒角和外观。
7. 给关键尺寸建立参数。
8. 修改参数测试模型稳定性。
9. 将可独立移动或制造的部分建为 Component。
10. 最后出图、导出或渲染。

## 初学者常见问题

- 只靠鼠标拖拽，不使用尺寸和约束。
- 草图没有完全约束就开始拉伸。
- 把整个装配建成一个实体。
- 太早添加圆角，导致后续特征难以修改。
- 使用固定数值，不使用参数。
- 一开始就追求复杂曲面或渲染，忽略基础建模。
- 从不通过修改参数验证模型稳定性。
- 导出 STL 前没有确认单位和壁厚。

## 12 周后的能力目标

完成本计划后，应能够：

- 独立完成常见机械或产品零件的参数化建模。
- 使用约束和参数控制尺寸变化。
- 建立多组件装配并设置基本运动。
- 生成基础工程图和 PDF。
- 为 3D 打印导出可用模型，或完成基础 CAM 刀路设置。
- 从实物、草图或需求出发，完成一个可展示、可迭代的设计项目。

## Git 上传说明

首次使用时配置 Git 身份：

```powershell
git config --global user.name "你的名字"
git config --global user.email "你的邮箱"
```

在项目目录中提交内容：

```powershell
git add README.md .gitignore
git commit -m "docs: add Fusion 360 learning plan"
```

在 GitHub、GitLab 或其他 Git 平台新建一个空仓库，然后绑定远程仓库并上传：

```powershell
git remote add origin https://你的Git平台地址/用户名/fusion360-learning-plan.git
git branch -M main
git push -u origin main
```

检查状态和远程地址：

```powershell
git status
git remote -v
```

以后更新学习计划：

```powershell
git add README.md
git commit -m "docs: update learning notes"
git push
```
