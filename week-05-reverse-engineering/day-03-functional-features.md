# 第 5 周·第 3 天：功能孔、槽与凸台

## 今日目标

将会影响装配和使用的功能结构加入复刻模型。

## 课程内容

1. 使用投影边界定位孔和槽。
2. 用 Hole 工具建立标准孔，手工草图只用于非标准开口。
3. 为凸台、卡扣和定位柱建立独立草图。
4. 检查功能结构与外壁的距离和壁厚。
5. 在每个特征后保存一个版本，便于回退。

## 动手练习

在主体模型上加入所有会影响安装和使用的孔、槽、凸台和卡扣；暂时保留容易争议的装饰细节。

## 本节重点总结

- 功能尺寸优先级高于外观尺寸。
- 独立特征便于后续测量修正和版本对比。
- 孔位与边缘距离过小会造成制造或强度问题。

## 完成检查

- [ ] 功能孔和槽已加入。
- [ ] 关键壁厚没有明显过薄。
- [ ] 每个主要功能特征都可独立修改。
