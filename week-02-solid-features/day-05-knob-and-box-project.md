# 第 2 周·第 5 天：旋钮与收纳盒综合练习

## 今日目标

综合使用拉伸、旋转、孔、圆角、倒角和抽壳，完成一组可识别的产品零件。

## 课程内容

1. 选择旋钮或收纳盒作为主项目，先画结构草图。
2. 旋钮使用多边形拉伸或旋转建立主体；收纳盒使用拉伸和抽壳。
3. 添加孔、凹槽或防滑纹理，适量使用阵列。
4. 最后处理圆角、倒角和外观。
5. 修改一个尺寸，确认时间线没有报错。

## 动手练习

完成 `knob-and-box_week02`：旋钮直径 `35 mm`、高度 `20 mm`，或制作 `120 x 80 x 40 mm` 的带盖前置收纳盒。至少使用本周 4 种建模命令。

## 本节重点总结

- 基础命令的价值在于能组合成可制造结构。
- 每做一个特征都要问：它表达的是尺寸、功能还是外观？
- 练习项目应至少完成一次尺寸回改，验证参数关系。
