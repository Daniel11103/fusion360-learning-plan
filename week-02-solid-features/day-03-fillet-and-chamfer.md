# 第 2 周·第 3 天：圆角与倒角

## 今日目标

理解 Fillet 和 Chamfer 的用途，掌握选择边、设置半径并避免特征失败。

## 课程内容

1. 在简单方块上分别添加外边圆角和内边圆角。
2. 比较 Constant Radius、Variable Radius 的适用场景。
3. 使用 Chamfer 的 Equal Distance 和 Two Distance。
4. 观察圆角顺序对后续孔、槽和阵列的影响。
5. 故意设置过大的圆角，阅读失败提示并调整。

## 动手练习

制作一个 `100 x 60 x 20 mm` 的设备底座：顶部四角 `R8`，底部外边倒角 `2 x 2 mm`，侧面开一个宽 `30 mm`、高 `10 mm` 的槽。

## 本节重点总结

- 圆角用于改善强度、手感和外观，倒角常用于去除锐边和导向。
- 圆角半径不能超过相邻几何允许的空间。
- 通常主体、孔槽完成后再处理最后的外观圆角。

## 完成检查

- [ ] 创建至少一个圆角和一个倒角。
- [ ] 处理过一次圆角失败。
- [ ] 能说明圆角应放在时间线后段的原因。
