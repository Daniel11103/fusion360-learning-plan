# 第 2 周·第 4 天：抽壳与壁厚

## 今日目标

使用 Shell 创建中空容器，理解开口面、壁厚和薄壁结构的制造限制。

## 课程内容

1. 建立一个带圆角的实体盒子。
2. 使用 Shell 选择顶部开口面，设置壁厚 `3 mm`。
3. 比较向内、向外和对称厚度的结果。
4. 为盒底和开口边添加圆角，观察结构变化。
5. 检查薄壁、尖角和过小圆角是否导致失败。

## 动手练习

制作 `storage-box_day04`：外部尺寸 `120 x 80 x 40 mm`，壁厚 `3 mm`，顶部开口，外角 `R6`，内底角做小圆角。

## 本节重点总结

- Shell 适合盒子、罩壳和容器类结构。
- 壁厚要结合材料和制造工艺，不能只追求最薄。
- 先确定开口面，再设置厚度；失败时检查尖角和相邻特征。
