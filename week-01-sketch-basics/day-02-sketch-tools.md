# 第 1 周·第 2 天：基础草图工具

## 今日目标

掌握直线、矩形、圆、圆弧、槽和多边形，能够用二维草图表达一个带孔安装板的基本轮廓。

## 课程内容

1. 新建草图并选择 XY 平面，观察草图坐标轴和原点。
2. 使用 Line 画中心线和轮廓线；用 Rectangle 创建矩形。
3. 使用 Circle 创建圆孔，理解圆心位置和直径尺寸。
4. 练习 Arc、Slot 和 Polygon，了解它们适合的结构。
5. 使用 Sketch(草图，素描) Dimension 标注外形长度、宽度、圆孔直径和孔距。
6. 退出草图并拉伸主体，检查草图轮廓是否闭合。

## 动手练习

建立 `mounting_plate_day02`：主体为 `120 x 70 mm`，厚度 `6 mm`；在中心线上布置两个直径 `8 mm` 的孔，孔中心距 `80 mm`。先完成草图，再拉伸主体并切除孔。

## 本节重点总结

- 草图由几何元素和约束共同定义，尺寸不是装饰而是设计信息。
- 闭合轮廓可以形成实体，开放轮廓通常用于中心线或特殊特征。
- 建孔时优先考虑孔的中心位置和直径，不要只凭视觉拖动。
- 命令名称和图标要同步记忆，之后可以减少对教程的依赖。
