# 第 3 周·第 2 天：投影与包含几何

## 今日目标

使用 Project / Include 将已有边、点和轮廓带入新草图，避免重复测量和手工重画。

## 课程内容

1. 在实体面上新建草图，使用 Project 投影外轮廓边线。
2. 练习投影单条边、多个边和整个轮廓。
3. 了解投影几何的关联性：源模型变化时草图如何更新。
4. 使用 Include 相关命令引用已有几何。
5. 用投影边界创建一个切除槽或凸台。

## 动手练习

在前一天的阶梯支架上投影立板边界，创建一个居中的 `30 x 12 mm` 槽，并让槽与外轮廓保持关联。

## 本节重点总结

- 投影可以把已有设计信息传递到新草图。
- 关联投影减少重复尺寸，但也要避免引用脆弱的短边。
- 选择稳定的基准和主要轮廓，有助于长期维护模型。
