# 第 3 周·第 1 天：构造平面与构造轴

## 今日目标

学会在非默认位置创建草图，理解偏移平面、中间平面、角度平面和构造轴。

## 课程内容

1. 在实体上创建 Offset Plane，设置偏移距离。
2. 使用 Midplane 在两面之间建立中心基准。
3. 创建 Angled Plane，观察草图方向变化。
4. 使用 Construction Axis 作为旋转或阵列参考。
5. 将草图命名为表达用途的名称，例如 `vent_sketch`。

## 动手练习

制作阶梯支架：主体底板 `100 x 60 x 6 mm`，在偏移平面上建立一块高 `40 mm` 的立板，并在立板上创建槽。

## 本节重点总结

- 构造几何不是实体，但能提供稳定的设计参考。
- 基准面应表达设计意图，而不是只依赖临时面。
- 中间平面特别适合对称结构和后续镜像。

## 完成检查

- [ ] 创建并使用一个偏移平面。
- [ ] 创建并使用一个构造轴。
- [ ] 新草图没有依赖容易消失的临时边线。
