# 第 3 周·第 3 天：镜像与矩形阵列

## 今日目标

使用 Mirror 和 Rectangular Pattern 快速创建对称结构和规则重复结构。

## 课程内容

1. 创建一个凸台或孔作为原始特征。
2. 使用 Mirror Features 选择中心平面进行镜像。
3. 使用 Mirror Entities 在草图内镜像几何。
4. 使用 Rectangular Pattern 设置数量、方向和间距。
5. 比较复制几何和复制特征对时间线的影响。

## 动手练习

制作散热板：底板 `120 x 80 x 5 mm`，在中心创建一条宽 `4 mm` 的槽，然后沿长度方向阵列 8 条槽，间距 `10 mm`，并镜像到另一侧。

## 本节重点总结

- 镜像适合左右对称，阵列适合规则重复。
- 优先阵列特征而不是手工复制草图，修改数量更方便。
- 阵列方向、数量和间距都应是明确的设计参数。
