# 参考答案说明

这里保存每周测试和综合测试的参考答案。请先完成试卷，再打开对应答案；不要把答案文件放在试卷末尾，避免测试时提前看到。

## 答案的使用方式

1. 先从空白文件完成试卷中的操作题和闭卷变式题。
2. 记录用时、文件名、分数和遇到的问题。
3. 再打开对应参考答案，逐项对照尺寸、约束、参数、组件、Joint、工程图或制造输出。
4. 对照后仍然不理解的项目，回到对应周课件重新练习。
5. 重新做一次变式题，确认不是只看懂答案。

## 如何理解参考答案

Fusion 360 通常有多种正确建模路径，因此答案提供的是：

- 必须满足的尺寸和功能条件。
- 推荐的命令或设计关系。
- 操作题的评分证据。
- 复盘题的合理回答范围。

只要模型满足设计要求、可修改、可解释，并且没有关键错误，不必和参考答案的时间线完全一样。
